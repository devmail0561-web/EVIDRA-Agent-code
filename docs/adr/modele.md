# Modèle d'ADR

Copier ce fichier vers `NNNN-titre.md`. Un ADR = une décision, numérotation
croissante, jamais de réécriture (une décision révisée = nouvel ADR qui
référence l'ancien).

```markdown
# ADR-NNNN — Titre

- Date : AAAA-MM-JJ
- Statut : proposé | accepté | révisé-par-NNNN
- Fonde : ETUDE_SA.md §X / PLAN_SA.md §Y (+ tâche TZ)

## Contexte

Ce qui force la décision (constat, contrainte, risque).

## Décision

Ce qui est tranché, sans ambiguïté.

## Conséquences

Ce que ça impose au code, aux tests, aux phases suivantes.

## Alternative rejetée

L'option écartée et pourquoi (en une phrase).
```
